# متابعة التدفقات النقدية الشهرية

تطبيق ويب لمتابعة المداخيل والمصاريف الشهرية.

## المزايا

- إدخال رصيد النقد الافتتاحي عند أول استخدام (قابل للتعديل لاحقًا)، ويُرحَّل تلقائيًا كرصيد ختامي من شهر لآخر.
- إدارة بنود مخصّصة للمداخيل والمصاريف (إضافة / تعديل / حذف).
- تسجيل يومي للعمليات (دخل أو مصروف) مرتبطة بالبنود المحددة مسبقًا.
- عرض شهري: التنقل بين الأشهر، ملخص (رصيد افتتاحي، إجمالي مداخيل، إجمالي مصاريف، رصيد ختامي)، وتوزيع حسب البند مع النسبة المئوية لكل بند.
- صفحة تقارير لمقارنة الأشهر ببعضها (الافتتاحي، المداخيل، المصاريف، صافي التغيّر، الختامي).
- إدارة البطاقات الائتمانية: إضافة بطاقة وحدها الائتماني، وتسجيل عمليات الشراء والسداد على كل بطاقة مع متابعة المستخدم والمتاح.
- متابعة القروض الشخصية: إضافة قرض بمبلغه وقسطه الشهري ومدته، وتسجيل الدفعات لمتابعة المسدد والمتبقي.
- ميزانية شهرية لكل بند (دخل/مصروف) مقارنة بالتدفقات الفعلية لنفس الشهر.
- تقويم التدفقات النقدية: عرض شهري يوضح صافي الدخل/المصروف لكل يوم.
- متابعة الاشتراكات الشهرية المتكررة مع يوم الاستحقاق وإجمالي التكلفة الشهرية.
- إدارة الإشعارات: تفعيل/إيقاف تنبيهات (اقتراب حد بطاقة، استحقاق اشتراك، تجاوز ميزانية، فرق في مطابقة الرصيد البنكي) ومتابعة التنبيهات النشطة حاليًا.
- تصدير العمليات والتقرير الشهري إلى ملف Excel/CSV.
- خانة للرصيد البنكي الفعلي مقارنة برصيد التطبيق لمتابعة أي فروقات.
- إدارة الاستثمارات: المبلغ، نوع الاستثمار، التطبيق/الجهة، وتاريخ الاستحقاق (اختياري).
- رسوم بيانية تفاعلية: المداخيل والمصاريف عبر الأشهر، اتجاه الرصيد الختامي، وتوزيع البنود — بالضغط على أي عمود أو قطاع لعرض تفاصيله.
- وضع داكن فقط، واجهة عربية بالكامل.
- تصميم متجاوب ومحسّن للجوال (آيفون خصوصًا: مساحات آمنة للنوتش، منع تكبير الحقول التلقائي، أزرار لمس أكبر).
- بحث وفلترة في العمليات اليومية (بالملاحظة أو اسم البند أو النوع) عبر كل الأشهر، وليس الشهر الحالي فقط.
- إضافة سريعة: زر عائم (+) ثابت أسفل يمين الشاشة في جميع الصفحات، يفتح نافذة سريعة لتسجيل عملية (دخل/مصروف) خلال ثوانٍ دون مغادرة الصفحة الحالية — مع اختصارات لأكثر 4 بنود استخدامًا وزر حفظ سريع بجانب المبلغ.
- عمليات متكررة تلقائية: سجّل دخل أو مصروف يتكرر كل شهر (مثل الراتب أو الإيجار) في صفحة مستقلة، وحدد يوم الشهر والشهور اللي يتكرر فيها، وتُضاف تلقائيًا كعملية عادية عند فتح التطبيق في الشهر المحدد.
- قابل للإضافة إلى الشاشة الرئيسية كتطبيق (PWA) بأيقونة مخصّصة، عبر `manifest.json` وأيقونات في مجلد `icons/`.
- تُحفظ البيانات محليًا في المتصفح (localStorage)، مع إمكانية تصدير نسخة احتياطية كاملة (JSON) واستعادتها لاحقًا — حتى من شاشة البدء نفسها إذا فُقدت البيانات.

تطبيق بملف واحد (`index.html`) بدون أي إعداد بناء (build) أو اعتمادات خارجية — فقط HTML وCSS وJavaScript عادي. يكفي فتح الملف مباشرة في المتصفح، أو استضافته على أي خدمة استضافة ثابتة (GitHub Pages مثلًا).
