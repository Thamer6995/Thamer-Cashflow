# متابعة التدفقات النقدية الشهرية

تطبيق ويب لمتابعة المداخيل والمصاريف الشهرية.

## المزايا

- إدخال رصيد النقد الافتتاحي عند أول استخدام، ويُرحَّل تلقائيًا كرصيد ختامي من شهر لآخر.
- إدارة بنود مخصّصة للمداخيل والمصاريف (إضافة / تعديل / حذف).
- تسجيل يومي للعمليات (دخل أو مصروف) مرتبطة بالبنود المحددة مسبقًا.
- عرض شهري: التنقل بين الأشهر، ملخص (رصيد افتتاحي، إجمالي مداخيل، إجمالي مصاريف، رصيد ختامي)، وتوزيع حسب البند.
- تُحفظ البيانات محليًا في المتصفح (localStorage).

## التشغيل محليًا

```bash
npm install
npm run dev
```

## البناء للإنتاج

```bash
npm run build
```
