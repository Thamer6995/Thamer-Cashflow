# متابعة التدفقات النقدية الشهرية

تطبيق ويب لمتابعة المداخيل والمصاريف الشهرية.

## المزايا

- إدخال رصيد النقد الافتتاحي عند أول استخدام (قابل للتعديل لاحقًا)، ويُرحَّل تلقائيًا كرصيد ختامي من شهر لآخر.
- إدارة بنود مخصّصة للمداخيل والمصاريف (إضافة / تعديل / حذف).
- تسجيل يومي للعمليات (دخل أو مصروف) مرتبطة بالبنود المحددة مسبقًا.
- عرض شهري: التنقل بين الأشهر، ملخص (رصيد افتتاحي، إجمالي مداخيل، إجمالي مصاريف، رصيد ختامي)، وتوزيع حسب البند مع النسبة المئوية لكل بند.
- صفحة تقارير لمقارنة الأشهر ببعضها (الافتتاحي، المداخيل، المصاريف، صافي التغيّر، الختامي).
- إدارة البطاقات الائتمانية: إضافة بطاقة وحدها الائتماني، وتسجيل عمليات الشراء والسداد على كل بطاقة مع متابعة المستخدم والمتاح.
- متابعة القروض الشخصية: إضافة قرض بمبلغه وقسطه الشهري ومدته، وتسجيل الدفعات لمتابعة المسدد والمتبقي.
- ميزانية شهرية لكل بند (دخل/مصروف)، مستقلة لكل شهر، مقارنة بالتدفقات الفعلية لنفس الشهر — مع خيار تطبيق نفس المبلغ على عدة أشهر دفعة وحدة (أغسطس حتى ديسمبر) بدل التنقل بين الأشهر وتكرار الإدخال، وشارة تنبيه تلقائية على أي بند تختلف ميزانيته من شهر لآخر مع عرض كل القيم المسجّلة له دفعة وحدة.
- تقويم التدفقات النقدية: عرض شهري يوضح صافي الدخل/المصروف لكل يوم.
- متابعة الاشتراكات الشهرية المتكررة مع يوم الاستحقاق وإجمالي التكلفة الشهرية.
- إدارة الإشعارات: تفعيل/إيقاف تنبيهات (اقتراب حد بطاقة، استحقاق اشتراك، تجاوز ميزانية، فرق في مطابقة الرصيد البنكي) ومتابعة التنبيهات النشطة حاليًا — مع خيار تفعيل إشعارات المتصفح لعرضها كإشعار حقيقي على الجهاز أثناء تشغيل التطبيق (بدون حاجة لسيرفر إضافي أو خطة مدفوعة).
- تصدير العمليات والتقرير الشهري إلى ملف Excel/CSV.
- خانة للرصيد البنكي الفعلي مقارنة برصيد التطبيق لمتابعة أي فروقات.
- إدارة الاستثمارات: المبلغ، نوع الاستثمار، التطبيق/الجهة، وتاريخ الاستحقاق (اختياري).
- رسوم بيانية تفاعلية: المداخيل والمصاريف عبر الأشهر، اتجاه الرصيد الختامي، وتوزيع البنود — بالضغط على أي عمود أو قطاع لعرض تفاصيله.
- وضع داكن فقط، واجهة عربية بالكامل.
- تصميم متجاوب ومحسّن للجوال (آيفون خصوصًا: مساحات آمنة للنوتش، منع تكبير الحقول التلقائي، أزرار لمس أكبر).
- بحث وفلترة في العمليات اليومية (بالملاحظة أو اسم البند أو النوع) عبر كل الأشهر، وليس الشهر الحالي فقط.
- إضافة سريعة: زر عائم (+) ثابت أسفل يمين الشاشة في جميع الصفحات، يفتح نافذة سريعة لتسجيل عملية (دخل/مصروف) خلال ثوانٍ دون مغادرة الصفحة الحالية — مع اختصارات لأكثر 4 بنود استخدامًا وزر حفظ سريع بجانب المبلغ.
- تسجيل عبر اختصار Siri/Shortcuts: يدعم التطبيق فتح نافذة الإضافة السريعة مباشرة ومعبّاة بالمبلغ عبر رابط مثل `?amount=25&type=expense` (type اختياري، الافتراضي مصروف)، أو حفظ العملية فورًا بدون أي لمسة عبر إضافة `&autosave=1` (بدون بند، بتاريخ اليوم) — يسمح بربطه باختصار شخصي في تطبيق Shortcuts يسأل عن المبلغ بالصوت ("Hey Siri...") ثم يفتح الرابط، فتنحفظ العملية تلقائيًا فور تأكيد الدخول.
- عمليات متكررة تلقائية: سجّل دخل أو مصروف يتكرر كل شهر (مثل الراتب أو الإيجار) في صفحة مستقلة، وحدد يوم الشهر والشهور اللي يتكرر فيها، وتُضاف تلقائيًا كعملية عادية عند فتح التطبيق في الشهر المحدد.
- قابل للإضافة إلى الشاشة الرئيسية كتطبيق (PWA) بأيقونة مخصّصة، عبر `manifest.json` وأيقونات في مجلد `icons/`.
- تسجيل دخول بالبريد الإلكتروني وكلمة المرور (Firebase Authentication)، ومزامنة البيانات تلقائيًا بين كل أجهزتك عبر Firestore — تسجّل عملية من الجوال وتلقاها فورًا على أي جهاز ثاني مسجّل بنفس الحساب.
- عند أول تسجيل دخول من جهاز فيه بيانات محفوظة محليًا من قبل، يعرض التطبيق خيار رفع هذي البيانات لحسابك الجديد أو البدء بحساب فارغ.
- تُحفظ نسخة محلية في المتصفح (localStorage) كذاكرة مؤقتة وتعمل حتى بدون إنترنت مؤقتًا، مع إمكانية تصدير نسخة احتياطية كاملة (JSON) واستعادتها يدويًا كطبقة حماية إضافية.
- التوقعات السنوية للتدفقات النقدية: صفحة مستقلة تعرض جدول متوقع/فعلي (الرصيد الافتتاحي، كل بند دخل وكل بند مصروف بنفس بنود صفحة "البنود"، إجمالي الإيرادات، إجمالي المصروفات، صافي الشهر، الرصيد الختامي)، مع أقسام قابلة للطي، عمود أول ثابت مع تمرير أفقي للأشهر وتمييز الشهر الحالي بلون مختلف، وتصدير Excel/CSV. نطاق سنة 2026 أغسطس-ديسمبر فقط (سنة البداية)، ومن 2027 يتوسّع تلقائيًا ليشمل السنة كاملة يناير-ديسمبر بدون أي تعديل يدوي — نفس المنطق ينطبق على اختيار الأشهر بلوحة "تطبيق على عدة أشهر" بصفحة الميزانية. كل رقم بالجدول يُلوَّن حسب قيمته: أخضر للموجب، أحمر للسالب (بين قوسين بدون كسور عشرية)، وأبيض بصيغة "-" للصفر بالضبط — مختلف عن "—" الرمادية التي تعني عدم توفر بيانات أصلًا لهذا البند. أرقام قسم المصروفات تُعرض دائمًا بالسالب (باللون الأحمر) لتوضيح إنها تدفقات خارجة، سواء بعمود المتوقع أو الفعلي. عمود "المتوقع" مبني فقط على بيانات حقيقية موجودة أصلًا في التطبيق (عمليات متكررة مجدولة، أو ميزانية الشهر عند عدم توفر عملية متكررة)، وعمود "الفعلي" هو مجموع العمليات الحقيقية المسجّلة لنفس البند والشهر — بدون أي أرقام افتراضية أو وهمية.

تطبيق بملف واحد (`index.html`) بدون أي إعداد بناء (build) — فقط HTML وCSS وJavaScript عادي، مع مكتبة Firebase محمّلة عبر CDN. يحتاج اتصال إنترنت لتسجيل الدخول والمزامنة، ومشروع Firebase خاص بك (مجاني ضمن الاستخدام الشخصي) — راجع قسم "الإعداد" بالأسفل.

## الإعداد (لمرة واحدة)

1. أنشئ مشروع على [console.firebase.google.com](https://console.firebase.google.com).
2. فعّل **Authentication → Email/Password**.
3. فعّل **Firestore Database** (وضع الإنتاج).
4. من **Firestore Database → Rules** الصق القواعد التالية وانشرها، عشان كل مستخدم يشوف بياناته فقط:
   ```
   rules_version = '2';
   service cloud.firestore {
     match /databases/{database}/documents {
       match /users/{userId} {
         allow read, write: if request.auth != null && request.auth.uid == userId;
       }
     }
   }
   ```
5. من إعدادات المشروع أضف تطبيق ويب، وانسخ `firebaseConfig` إلى داخل `index.html` (بحث عن `firebaseConfig`).
